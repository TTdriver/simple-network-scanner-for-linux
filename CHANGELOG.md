# Changelog

All notable changes to Simple Network Scanner will be documented here.

## [Unreleased]

- Improved scan button styling, spacing, and table readability.
- Added horizontal result scrolling and clearer MAC discovery wording.
- Preserved results when selecting another scan type.
- Improved early cancellation and scan lifecycle handling.
- Reported missing or malformed results as scan errors.
- Added a per-user installer with desktop and menu launchers.

## [1.0.0] - 2026-07-28

### Added

- Application version displayed in the title bar

### Changed

- Device results now clear when the scan type is changed
- Local host MAC field displays `Host device`
- Local host vendor field displays `This computer`
- Local host latency displays `Local host`
